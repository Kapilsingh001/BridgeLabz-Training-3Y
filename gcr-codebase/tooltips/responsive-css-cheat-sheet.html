Responsive CSS Cheat Sheet

Quick reference for important responsive CSS concepts.

Filters

filter: grayscale(100%); applies visual effects such as grayscale, blur, sepia, brightness, and contrast.

Media Queries

@media (max-width: 700px) applies CSS rules when the screen width is 700px or smaller.

Responsive Grid

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); creates a flexible grid layout.

Flexbox

display: flex; arranges elements in rows or columns and provides flexible alignment.

Typography

font-size: clamp(1rem, 2vw, 1.5rem); makes text size responsive.

Spacing

gap: 20px; creates consistent spacing between grid or flex items.

Transition

transition: 0.3s ease; creates a smooth change between CSS states.

Transform

transform: scale(1.05); changes the size or position of an element.
