Responsive Design Principles

Core concepts for creating responsive websites.

Fluid Layouts

Fluid layouts use relative units such as percentages, vw, and fr so that elements can adapt to the available screen width. 


.container {
    width: 90%;
    max-width: 1200px;
}

Flexible Media

Flexible media allows images and other media to scale within their containers without overflowing the screen. 


img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints allow different CSS rules to be applied according to the screen size using media queries. 


@media (max-width: 600px) {
    .container {
        display: block;
    }
}
