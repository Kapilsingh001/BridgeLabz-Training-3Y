CSS Box Model

Understanding Content, Padding, Border and Margin

Box Model Layers

Content

Content

The content is the actual text or information inside an HTML element.

Padding

Padding creates space between the content and the border.

Border

The border surrounds the content and padding of an element.

Margin

Margin creates space outside the border, separating elements from each other.
