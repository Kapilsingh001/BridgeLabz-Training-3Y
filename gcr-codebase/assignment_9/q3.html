What is jQuery?

jQuery is a fast, small JavaScript library that makes DOM manipulation, events and animations easier.

How do I include jQuery in my project?

Add a <script> tag pointing to the jQuery CDN before your own script file.

What does $(document).ready() do?

It runs your code only after the HTML document has been fully loaded and parsed.

What is the difference between .hide() and .slideUp()?

.hide() hides instantly (or with a size/opacity animation), while .slideUp() animates the height to zero.

Can I use jQuery with modern JavaScript?

Yes. jQuery works alongside ES6+ features such as arrow functions, let/const and template literals.
